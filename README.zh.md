# 牛来掼蛋

[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

先说怎么开打：建房，把四位房间码丢给对面，人不够就点开始，三个机器人会坐下。进房页右上可以切 中 / 日 / EN。

这不是一副普通花色。红桃是那头正脸黄牛，方片张着嘴，梅花发呆，黑桃不耐烦；小王冷银半眼，大王镀金侧目。图都从 [niulai.co](https://niulai.co/) 的正片截图修过，抠了白底，不是另画一张「很像牛来」的脸。

![这桌的牌面](docs/card-faces.png)

## 这桌怎么计

两副牌，每人 27 张。级牌从 2 打到 A，红心级牌是逢人配。双下 +3，一三 +2，一四 +1。打上 A 再赢一局，这副牌就结束。非双下要进贡，没有抗贡。

掉线会立刻托管，回到原来的座位。人的回合 90 秒不动作也托管。发牌先飞牌背，落完再整手翻开，中间只留出牌区，牌堆贴在各自身边。

## 自己跑

```bash
npm install
npm start
```

浏览器开 `http://主机:8787`。这是带 Socket.IO 的桌子，GitHub Pages 撑不住；要长期挂着，用仓库里的 Render 按钮（英文 README 里）。
