# 牛来の貫蛋

[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

映画『牛来』の黄色い仔牛が、そのまま札になっている卓。4人2チームのカンダンで、部屋は4桁のコード。人が来なくても「開始」を押せばロボットが3人座る。表示はロビーで 中 / 日 / EN。

札の顔は [niulai.co](https://niulai.co/) の本編スチルを切って抜いた。似せたイラストではない。ジョーカーだけ別扱い：小王は銀の半眼、大王は金の横目。並ぶと「強い札」に見えるようにしてある。

![札の顔](docs/card-faces.png)

## この卓の約束

108枚、手札27。レベルは2からA。そのレベルのハートがワイルド。得点はダブルダウン+3、1と3で+2、1と4で+1。Aまで上がって、もう1回勝てば試合終了。双下以外は進貢あり。抗貢はなし。

切れた人はすぐ自動打ち。戻ると同じ席。人間の番は90秒。配札は裏向きに弧を描いて飛び、揃ってから一気に裏返す。山札は卓の真ん中ではなく、各席のそば。

音声は任意。マイクを拒んでも遊べる。
